# Notes App

## About
A simple Notes App built using React to write and save important notes.

## Features
- Add new notes
- Edit existing notes
- Delete notes
- Add note title and description
- Display notes in cards
- Responsive design

## Technologies Used
- HTML
- CSS
- JavaScript
- React

## How to Run
1. Clone the repository.
2. Open the project folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
